lemma_docs_mcp
Lemma practice-banking docs, indexed for agents

A local, read-only Model Context Protocol server that indexes the Lemma (getlemma.com) documentation — healthcare-practice banking: entity accounts, deposit bonuses, fixed fee loans, cash sweeps, and MSO-PC compliant banking guardrails — and serves ranked context search + exact chunk retrieval to any MCP client. It never calls live Lemma or banking APIs, and never redistributes Lemma content — corpus stays local, code ships alone.

What's not in the corpus

Lemma's docs platform only exposes 8 pages as markdown. These sections exist on getlemma.com but are not indexed — the tools say so instead of guessing: banking operations (accounts, cards, transactions, checkbooks, move money, external accounts, cash sweeps detail, mobile check deposit), insurance & billing (lockbox, EOB processing, reconciliation, patient refunds, EFT re-enrollment), invoicing, team management & approval rules, and the full API reference (auth, webhooks, transfers, ACH). Expansion paths: request an official export from Lemma, or add a scraping/browser-crawl layer — see NOTICE.md.

Tool contracts

ToolPurposeKey parameters
lemma_docs_context Ranked excerpt search for a question or task. Routes to a namespace, returns compact chunks with source paths, follow-up hints, and paging. query · namespace (auto default) · intent (answer / build_context / source_map) · max_chunks 1–12 · offset · response_format
lemma_docs_get Full text of specific chunks by id, or every chunk of one document by path. The expansion step after search — not a browser. ids (≤8) · path · response_format

Both tools declare readOnlyHint, idempotentHint, openWorldHint:false and attach SDK-validated structured content alongside markdown.

Design decisions

  • Same architecture as its siblings (whop_docs_mcp, stedi_docs_mcp, ghl_docs_mcp, elevenlabs_docs_mcp, fullscript_docs_mcp): stdio, two read-only tools, in-memory index, fixture + wire-protocol test suites.
  • Filename-prefix routing. The Lemma corpus is flat (lemma-docs-<section>-…): quickstart → getting-started; changelog/roadmap → product-updates; guides-* → guides.
  • Honest about coverage. The 8-page corpus is everything Lemma exports as markdown; empty-result guidance and tool descriptions name the missing sections explicitly so agents don't hallucinate banking-operations answers.
  • Docs-server, not live-server. Look things up here; any live Lemma/banking integration is a separate, write-gated decision — this server can never move money.
  • Content licensing. Code only is distributable; the corpus is © Lemma, stays local, and redistribution permission is an unconfirmed placeholder — see NOTICE.md before publishing anything.
  • Corpus refresh. Re-download any page as raw markdown from getlemma.com/docs/<path>.md; the index rebuilds on next server start. The changelog/roadmap pages keep the corpus current with weekly releases.
